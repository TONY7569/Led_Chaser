# LED Pattern Generator Using 4017 & 555 Timer

This project creates beautiful LED patterns (like numbers and stars) using a 555 timer in astable mode and a CD4017 decade counter, without any microcontroller. Ideal for electronic art and educational displays.

## 🔧 Components Used
- 555 Timer IC
- CD4017 Decade Counter
- Resistors, Capacitors
- 50+ LEDs
- Custom PCB

## 💡 Working Principle
The 555 timer produces clock pulses which the CD4017 uses to turn on LEDs in sequence. Patterns are designed through PCB layout.

- Proteus simulation files
- Circuit diagram and PCB layout
